## Miten aktivoin EasyKeychain K-9 Mail ohjelmassa?
To use EasyKeychain with K-9 Mail, you want to follow these steps:
  1. Open K-9 Mail and long-tap on the account you want to use EasyKeychain with.
  2. Select "Account settings", scroll to the very bottom and click "Cryptography".
  3. Click on "OpenPGP Provider" and select EasyKeychain from the list.

## Löysin bugin EasyKeychain ohjelmassa!
Please report the bug using the [issue tracker of EasyKeychain](https://github.com/openpgp-keychain/openpgp-keychain/issues).
